# homicron Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public git repository of bash that installs Helios on a bare-metal x86 machine from one typed console line and then prepares it as a voxel host over SSH, served by GitHub Pages at `https://homicron.smithjs.org`.

**Architecture:** Three stages of bash split by where they run: `install/install.sh` in the installer ramdisk, `firstboot/` as a one-shot SMF service on the installed system, and `host/NN-*.sh` idempotent steps driven over SSH by the laptop-side runner `bin/homicron`. A GitHub Actions workflow lints every script and deploys a static `_site/` built from the stage directories. A qemu/KVM harness on an x86 Linux host rehearses every stage.

**Tech Stack:** bash 5, bats-core for tests, shellcheck, GitHub Actions (`actions/upload-pages-artifact`, `actions/deploy-pages`), qemu-system-x86_64 with KVM and OVMF, illumos tools on the target (`ipadm`, `dladm`, `svccfg`, `svcadm`, `zfs`, `pkg`, `useradd`, `usermod`).

**Spec:** `docs/superpowers/specs/2026-10-31-homicron-design.md`

## Global Constraints

- Every script starts with `#!/bin/bash` and `set -o errexit -o pipefail -o nounset`. Target scripts must run on Helios `/bin/bash`; laptop scripts must run on macOS bash 5 from Homebrew and on Linux.
- No private host names, addresses, or machine details in any committed file. Private values come from the environment. A variable set in the environment wins over `hosts/<name>.env`.
- The site base URL defaults to `https://homicron.smithjs.org`; `HOMICRON_BASE_URL` overrides it.
- Every path a script writes to or reads from on the target has an environment override with the default from the spec, so tests can run on a laptop: `HOMICRON_ALTROOT=/a`, `HOMICRON_CONF=/etc/homicron.conf`, `HOMICRON_MSGLOG=/dev/msglog`, `HOMICRON_DIR=/opt/homicron`, `HOMICRON_LOG_DIR=/var/log/homicron`, `HOMICRON_ETC=/etc`, `HOMICRON_HOME=/home`.
- Tests fake target commands by prepending a directory of fake executables to `PATH`. No test runs a real `zfs`, `ssh`, `rsync`, `curl`, `pkg`, or `qemu`.
- `shellcheck` and `bash -n` must pass on every script before commit. `test/lint.sh` is the single command for that.
- Exit codes: 0 success, 2 usage or configuration error, 10 (steps only) reboot required, 1 any other failure.
- Commit after every task with a message that names the component.

## Review Focus

1. A hostname with characters illumos `nodename` rejects (spaces, uppercase, underscores) must be refused by `install.sh` with exit 2 before the disk is touched. Pinned in Task 4.
2. An empty or missing `keys/authorized_keys` would install a machine nobody can log in to; `install.sh` must exit 1 before calling `install-helios`. Pinned in Task 4.
3. A link that already has only an IPv6 link-local address object must still get a DHCP v4 address from the first-boot service, so the check is for a `/v4` object, not any object. Pinned in Task 3.
4. `pkg update` exits 4 when there is nothing to do; `30-pkg.sh` must treat 4 as success and 0 as "check whether a new boot environment appeared". Pinned in Task 8.
5. When the box is unreachable, `ssh` exits 255; the runner must report "cannot reach <addr>" and exit 1 rather than blaming the current step. Pinned in Task 6.

- [ ] **Step 3: Write `firstboot/homicron-firstboot`**

### Task 6: Laptop runner and box-side step runner

**Files:**
- Create: `bin/homicron`, `host/run-step.sh`, `host/lib.sh`
- Test: `test/homicron.bats`, `test/run-step.bats`

**Interfaces:**
- Produces: `bin/homicron apply <name>` and `bin/homicron ssh <name>`. Repo root is the parent of `bin/`. Sources `hosts/<name>.env` with environment precedence (implement as: for each line `KEY=VALUE`, set only if `KEY` is unset). Required: `HOMICRON_USER`, `HOMICRON_UID`. Defaults: `HOMICRON_ADDR=<name>.local`, `HOMICRON_PORT=22`, `SWAP_SIZE=16G`, `DUMP_SIZE=16G`, `FALCON_DATASET=`, `VOXEL_REF=main`, `VOXEL_SLEDS=4`, `VOXEL_SLED_MEMORY_GB=8`. Env knobs: `HOMICRON_POLL_SECONDS=5`, `HOMICRON_REBOOT_TIMEOUT=600`.
  - `apply`: `rsync -az --delete -e "ssh -p $PORT" host/ root@$ADDR:/opt/homicron/`, then `rsync` the env file to `root@$ADDR:/opt/homicron/host.env` and `keys/authorized_keys` to `root@$ADDR:/opt/homicron/authorized_keys`; then for each `host/[0-9][0-9]-*.sh` sorted: `ssh -p $PORT root@$ADDR /opt/homicron/run-step.sh <basename>`; exit 0 continue; exit 10 → `ssh ... reboot || true`, poll `ssh -o ConnectTimeout=5 ... true` every `HOMICRON_POLL_SECONDS` until success or `HOMICRON_REBOOT_TIMEOUT`, rerun the same step once and require 0; exit 255 → print `cannot reach $ADDR` and exit 1; any other → `ssh ... cat /var/log/homicron/<step>.log`, print `step <name> failed with status N`, exit N.
