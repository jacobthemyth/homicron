homicron

homicron installs Helios on a bare-metal x86 machine and prepares it to run voxel.

Install

Boot the stock Helios installer ISO. At its root prompt, find the NIC with dladm show-phys and the disk with diskinfo, then type:

ipadm create-addr -T dhcp <nic>/v4 && echo "nameserver $(dhcpinfo -i <nic> DNSserv)" > /etc/resolv.conf && curl -fsSLo /tmp/i {{BASE_URL}}/install && HOMICRON_KEYS_URL=https://github.com/<user>.keys bash /tmp/i <hostname> <disk>

HOMICRON_KEYS_URL names the public keys root will accept. GitHub serves yours at that address.

The second command is needed because the installer ramdisk ships an empty /etc/resolv.conf and DHCP does not fill it, so the name would not resolve.

When it prints install complete, remove the media and run reboot.

What happens

  1. The install wrapper verifies every file it fetched against SHA256SUMS, runs install-helios, and seeds the new root with SSH keys and a first-boot service.
  2. On first boot, the service brings up DHCP on every NIC, enables sshd and mDNS, prints the address on the console, and disables itself.
  3. From your workstation, bin/homicron apply <name> runs the idempotent host steps over SSH: user, swap and dump, packages, Rust, the falcon dataset, and the voxel build.
